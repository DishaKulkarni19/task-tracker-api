# Task Tracker API

Beginner-level Django REST application demonstrating:
- CRUD operations
- PostgreSQL (Supabase) integration
- Third-party API usage
- Data reporting

## Tech Stack
- Python
- Django
- Supabase

## Run Instructions
1. Install dependencies
2. Configure database
3. Run migrations
4. Start server

## APIs
- /api/tasks/
- /api/quote/
- /api/report/
